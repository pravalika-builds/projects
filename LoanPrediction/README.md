# AI Loan Approval Prediction

## Project Description
This project predicts whether a loan application is likely to be approved based on the applicant's financial details.

## Features
- Monthly Income input
- Credit Score input
- Loan Amount input
- Existing Loans input
- Loan approval prediction
- Simple user-friendly interface

## Technologies Used
- Python
- Tkinter
- Machine Learning

## How to Run
1. Open the project in VS Code.
2. Open the terminal inside the LoanPrediction folder.
3. Run:

python app.py

## Output
The application displays whether the loan is approved or not.
